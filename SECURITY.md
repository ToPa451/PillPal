# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through a public GitHub issue. Instead, report them through the maintainer's GitHub profile:

<https://github.com/ToPa451>

If possible, include:

- the affected version
- the affected component or feature
- the steps required to reproduce the issue
- the potential impact
- any existing mitigations or proposed solutions

I will make reasonable efforts to review and address incoming reports in a timely manner. However, I cannot guarantee a fixed response or remediation time. Please do not publicly disclose details of a potential vulnerability until a solution has been agreed upon or sufficient time has been allowed for investigation.

Please do not include private or sensitive information in public issues or discussions. This includes screenshots or exports showing medications, names, dosages, schedules, health information, Home Assistant user data, tokens, or other identifying details. Redact or anonymize such information before sharing it, and use a private reporting channel for anything that cannot be safely anonymized.

## Supported Versions

| Version | Security updates |
| --- | --- |
| Current version | Yes |
| Future versions | Yes |
| Older versions | No |

## Scope

This policy covers security vulnerabilities in this repository and in the Pill★Pal integration, particularly in the Python code, frontend, config flow, APIs, data validation, and access control.

Issues related to an individual Home Assistant installation, insecure add-ons, network configuration, or backup configuration are outside the scope of this reporting channel. Pill★Pal is not a substitute for medical advice. Dosage and treatment decisions must not be based solely on this integration.
